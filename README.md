# Код і дані до статті «Ймовірнісно-вартісна модель стратегій перевірки фінальності для легких клієнтів блокчейнів із доказом частки»

Запуск (близько двох хвилин на ноутбуці):

```
pip install -r requirements.txt
python finality_model.py
```

- `finality_model.py` — модель безпеки (гіпергеометрична модель; точне інтегральне подання зваженої вибірки без повернення; перевірка методом Монте-Карло), модель вартості (такти, байти, газ EVM), усі таблиці й рисунки. Початкове значення генератора випадкових чисел: 20261004.
- `requirements.txt` — версії пакетів, з якими отримано результати (Python 3.11).
- `data/` — знімки публічного RPC NEAR від 04.10.2026: `near_protocol_config.json`, `near_lcb.json`, `near_lcb_prev.json`, `near_status.json`, `near_validators_compact.json`.
- `results/` — T0 (параметри з джерелами), T1 (k* для рівних стейків), T2/T2b (зважені стейки), T3 (перевірка методом Монте-Карло), T4 (NEAR, n = 100), T5 (точки перетину), T6 (граничне G_Ed), T7 (чутливість до недооцінки f), T8 (дані для рис. 5), near_snapshot_stats.json.
- `figures/` — рис. 1–6 (PNG, 300 dpi).

Опубліковані виміри доказу фінальності використано лише як вхідні параметри: Kuznetsov et al. (2024a), LNNS 1091, с. 275, табл. 4; Kuznetsov et al. (2024b), CEUR-WS 3826, с. 99–102. Нових запусків Plonky2 не виконувалося.
